# Картинки для публикаций @victoria_coach_de

Публичное хранилище слайдов, одобренных к публикации.

Instagram Graph API забирает изображения **только по постоянным публичным
HTTPS-ссылкам** — локальные файлы и временные ссылки он не принимает.
GitHub Pages раздаёт такие ссылки бесплатно, но только для публичных
репозиториев. Поэтому картинки живут отдельно от всего остального.

## Что здесь есть

Только JPEG 1080×1350 — слайды каруселей, которые и так выходят
в Instagram и становятся публичными.

## Чего здесь нет и не будет

Кода агента, профиля и голоса Виктории, методички по каруселям, журнала
решений, черновиков, оригиналов фотосессии, токенов и любых секретов.
Всё это остаётся в приватном репозитории.

## Структура

```
media/<название-карусели>/01.jpg … 10.jpg
```

Адрес файла: `https://viktoriyabusinesscoach-art.github.io/instagram-approved-media/media/<карусель>/01.jpg`
